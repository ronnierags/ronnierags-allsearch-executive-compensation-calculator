---
name: Calculator preservation
description: Product constraint for future changes to the AllSearch compensation calculator.
---

Preserve the approved compensation calculator’s existing visual design and calculation behavior when extending the product. Add new capabilities around the calculator rather than redesigning or rewriting its modeling logic.

**Why:** The user explicitly approved the imported calculator and required that implementation work retain its logic and design.

**How to apply:** Treat the calculator UI and formulas as compatibility constraints. Limit future changes to requested integrations, workflows, accessibility fixes, and clearly approved enhancements.
